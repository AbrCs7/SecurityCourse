# 🔐 Curso de Segurança da Informação — Recursos e Testes

Este repositório contém arquivos utilizados no contexto de **estudos e testes em segurança da informação**, voltado para aprendizado e simulações controladas.

⚠️ **AVISO IMPORTANTE**

> Este repositório contém **malwares, scripts maliciosos, e outros arquivos perigosos**, que devem ser utilizados **exclusivamente em ambientes de teste e pesquisa controlados**.

**NUNCA execute qualquer arquivo deste repositório em sistemas de produção ou máquinas pessoais.** Sempre utilize ambientes isolados, como VMs (máquinas virtuais) ou sandboxes.

## 📚 Objetivo

O objetivo deste repositório é fornecer exemplos reais de:

- Vírus simples (educacionais)
- Exploits conhecidos
- Ferramentas de análise estática e dinâmica
- Técnicas de engenharia reversa

Todos os arquivos aqui presentes são para fins **educacionais e de pesquisa** somente.
